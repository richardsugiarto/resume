# Exist-Mate(Internship)
**Project Type:** Full-stack Web Application

## Overview
Developed a Django-based web application for restaurant operations that centralizes menu presentation, booking management, and image uploads.

![Existmate login page](/experience-md/existmatefd/image2.png)

## Problem Solved
Replaced manual menu updates and fragmented booking records with a single web interface for staff and customers to view menus, manage reservations, and upload menu photos.

## Role & Responsibilities
**Role:** Full-stack Developer  
- Designed backend models and views using Django  
- Implemented frontend templates and JavaScript interactions  
- Integrated third-party UI libraries  
- Managed database migrations and static/media asset handling  

## Tech Stack
- **Backend:** Python, Django  
- **Frontend:** HTML, CSS, JavaScript, jQuery  
- **UI & Plugins:** Bootstrap, Dropzone.js, Slick, Perfect Scrollbar  
- **Database:** SQLite / MySQL  
- **Tools:** Git  

## Key Features & Technical Highlights
- Responsive menu listing and detail pages  
- Booking list and detailed booking views for staff management  
- Drag-and-drop image uploads using Dropzone integrated with Django media endpoints  
- Reusable Django templates with well-organized static asset structure  
- Django admin integration and database migrations for schema evolution  

## Challenges & Solutions
- **Large static assets & plugin integration:**  
  Organized assets under app-specific static folders and lazy-loaded JavaScript to reduce page weight.

- **File upload reliability:**  
  Implemented server-side validation and integrated Dropzone hooks to surface upload errors to users.

## Results & Impact
Delivered a functional prototype that streamlines menu updates and booking handling, simplifying daily operations and enabling faster content updates without printing or manual coordination.
